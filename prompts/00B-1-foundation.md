# 0B-1 — 저장소·환경·테스트 기반

## 목표

Python 3.12, FastAPI/Jinja2, PostgreSQL, SQLAlchemy/Alembic 기반의 최소 실행·테스트 골격과 원본 디자인 보호 장치를 만든다.

## 선행 게이트

0A-2 운영 문서와 승인된 디자인 해시 기준표가 존재해야 한다.

## 수행

1. 활성 규칙과 현재 코드/패키지 메타데이터를 조사해 최소 `pyproject`, 앱 구조, 설정, 마이그레이션, 테스트 구조를 설계·구현하라.
2. 개발·테스트 DB를 격리하고 UTC 저장/Asia/Seoul 표시 규칙을 적용하라.
3. 환경변수 기반 설정과 비밀정보 로그 차단을 구현하라.
4. 원본 HTML 9개 해시 검사와 줄바꿈 보호를 자동화하라.
5. `src/wemeet_ai`는 `docs/ARCHITECTURE.md`에 기록된 0A-1의 KEEP/ADAPT/REPLACE/DROP 판정을 따르되, 아래 검증 결과가 기존 근거와 다르면 같은 문서의 판정과 근거를 수정하고 변경 이유를 기록하라. 같은 역할의 구조를 두 벌 두지 마라.

범위 밖: 인증 UI, 그룹 기능, AI LIVE 호출, AI 작업 상태 저장 구현, 원본 HTML 수정.

## 검증

- 깨끗한 환경에서 설치, 앱 import, 마이그레이션 up/down/up, 테스트 DB 격리를 확인하라.
- 설정 누락·잘못된 DB URL·비밀 로그에 대한 실패 테스트를 포함하라.
- 크리퍼 저장소의 기존 결정적 테스트를 원본을 수정하지 않고 실행해 0A-1 모듈 판정을 재확인하고, 통과·실패·미실행 항목과 판정 변경 여부를 `docs/ARCHITECTURE.md`에 기록하라.
- 결정적 테스트를 실행하고 결과를 기록하라.
- 원본 HTML 해시 검사를 두 번 실행해 승인 기준과 동일함을 확인하라.

## 중단 조건

새 주요 데이터베이스/큐/프런트엔드 프레임워크가 필요하거나 외부 계정이 필요하면 사용자 승인 전에 중단하고 BLOCKED로 보고한다.
