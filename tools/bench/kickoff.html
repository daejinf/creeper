    공동 목표와 공동 계획

    개인 기여 목표와 내 과제

    운영 서비스에서는 SW 인증으로 본인만 조회하도록 연결해야 합니다. 아래 선택은 로컬 테스트용입니다.

    다음 평가 모듈에 전달할 ID

    확인한 평가 기준의 baseline_id와 plan_version_id, task_id를 함께 사용합니다. 과거 버전은 수정하지 않습니다. M2 평가 기능 자체는 아직 실행하지 않습니다.

    내 기여 목표·조건 검토

    AI 추천을 수정·확인한 뒤 개인 계획을 만듭니다. 미정인 수준·시간은 직접 확인하며 임의로 채우지 않습니다.

    수정·확인은 코드 처리, 계획 생성은 실제 API 호출입니다. 운영 서비스의 최종 승인을 대신하지 않습니다.
