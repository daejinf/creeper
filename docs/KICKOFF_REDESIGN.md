# 킥오프 화면 사용성 개선

AI 코어·API·SQLite 계약을 변경하지 않고, 삽입 화면의 읽기 공간을 재구성했습니다. 유료 호출 없이 저장된 실제 코칭 응답으로 확인했습니다.

## 바뀐 사용법

1. **대화 코칭:** 팀 대화와 AI를 나란히 봅니다. 최신 답변을 처음부터 표시하며 이전 코칭은 펼쳐 볼 수 있습니다. 실행 버튼은 답변을 스크롤해도 움직이지 않습니다.
2. **넓게 보기:** AI 영역을 전체 너비로 펼칩니다. `나란히 보기`로 돌아갑니다. 작은 화면에서는 `AI와 함께 보기 / 팀 대화만 보기`로 한 화면씩 전환합니다. 이 전환은 AI를 호출하거나 대화를 삭제하지 않습니다.
3. **목표 정리 / 내 계획 상담 / 실행 계획:** 같은 넓은 작업 영역을 사용합니다. 개발자 요청·응답·Python 예제는 하단에서 열며, 창을 열어도 본문의 높이를 줄이지 않습니다. 같은 제목을 다시 누르면 닫힙니다.

모델·토큰·지연시간은 `실행 정보`를 열어 확인합니다. 오류는 접힌 실행 정보에만 숨기지 않고 별도 안내로 표시합니다.

## 확인 결과

기존 화면의 문제는 답변의 글자 크기보다 **여러 겹의 안내·고정 높이·중첩 스크롤 때문에 실제 답변이 두 줄 정도로 줄어드는 것**이었습니다. 데모의 불필요한 바깥 사이드바를 제거하고, 헤더와 버튼 영역을 줄였습니다. AI 답변은 작은 말풍선 대신 문서 형태로 읽을 수 있습니다.

| 화면 크기 | AI 답변 높이 | 가로 넘침 | 코칭 버튼 |
|---|---:|---|---|
| 390 × 844 | 461px | 없음 | 하단에 표시 |
| 768 × 900 | 491px | 없음 | 하단에 표시 |
| 1024 × 768 | 348px | 없음 | 하단에 표시 |
| 1440 × 900 | 474px | 없음 | 하단에 표시 |

- 기본 1280 × 720에서도 답변 높이는 294px입니다. `넓게 보기`를 함께 제공합니다.
- 긴 답변의 시작·끝으로 키보드 스크롤 후에도 버튼 위치가 유지됩니다.
- 팀 대화↔AI 전환 후 전송하지 않은 문장이 유지됩니다. 임시 검사 입력은 원복했습니다.
- 목표 정리·개인 상담·계획 탭과 기존 기록 표시를 확인했습니다. 대화 변경으로 재검토가 필요한 기존 조건을 새로 확정하지 않았습니다.
- 개발자 실행 내역은 별도 레이어로 열리고 닫힙니다. 조회에는 모델 호출이 없습니다.
- 자동화 회귀 검사 156개 통과. 기존 FastAPI TestClient/httpx 경고 1건이 있습니다.
- 이번 작업은 UI 사용성 검사이며, 새로운 모델 응답의 의미적 품질이나 접근성 인증을 완료한 것은 아닙니다.
